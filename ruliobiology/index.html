Ruliobiology Stack

Symmetric 2D cellular automata, evolved by single-point mutation. Each step is stacked below the last.

Rule space

More colors → many more rule cases. Mutations to cases the organism never uses are neutral and cost nothing, so the budget scales up automatically.

Selection

Patterns that never die get fitness 0. A mutation is kept if fitness doesn't decrease.

Fitness

Genome

Blocks by center color. Each square is a rule case (center + symmetric neighbor set); its color is the outcome. Outlined = used by this organism.

Recurring substructures

Counts every s×s patch centered on a non-white cell in every time layer. Patches that are rotations or reflections of each other count as the same motif.

Motif recurrence

Rows ranked by how many columns contain the motif, then by total count. Shading = log count. Click a row to highlight that motif in 3D. In generation/population mode, clicking a cell also loads that organism.

Conserved rule cases

Rows = rule cases the organisms actually use (sorted by first use). A colored cell means the case is used in that column, colored by its outcome. Long unbroken rows are conserved "genes".
