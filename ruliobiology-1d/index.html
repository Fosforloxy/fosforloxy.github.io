1D RulioOrganisms

1D2D3D
1D cellular automata, evolved by single-point mutation. A row of cells grows from one seed; each step is drawn below the last, so an organism's whole life is one picture.
← Catalog · Wolfram’s 1D model ↗

Rule space

A cell looks at itself and its two neighbours. With symmetry on, a case and its mirror image share one outcome, and organisms stay symmetric about the seed. The all-white case always stays white.

Selection

Patterns that never die get fitness 0. A mutation is kept if fitness doesn't decrease.

Evolution

A mutant that never dies is run all the way to the cutoff. In 1D that is cheap, so the cutoff can be high.

Fitness

Gray = all lineages · dark line = selected lineage. Fitness rises in steps, with long plateaus of neutral drift between them.

Genome

One square per rule case, in rows by center color; its color is the outcome. Dark-edged = used by this organism.
